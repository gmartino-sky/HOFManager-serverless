# 📚 HOF Manager - Commands Guide

This guide explains each available command in **HOF Manager**, including its purpose and usage examples, provided in **English**, **Spanish Latino**, and **Simplified Chinese**.

---

# `/donation`

**Purpose:** Report a gold donation made by a character.

- 🇬🇧 **English**: 
  > Use `/donation` to submit which character donated, how, to which clan, and the date.

- 🇪🇸 **Español Latino**:
  > Usa `/donation` para reportar qué personaje donó, cómo, a qué clan y en qué fecha.

- 🇨🇳 **Simplified Chinese**:
  > 使用 `/donation` 来提交哪个角色捐赠了金币、方式、所属官民和日期。

---

# `/history-user`

**Purpose:** View your donation history.

- 🇬🇧 **English**: 
  > Use `/history-user` to view weekly donation status across your Main and Alt characters.

- 🇪🇸 **Español Latino**:
  > Usa `/history-user` para ver el estado semanal de donaciones de tus personajes Main y Alt.

- 🇨🇳 **Simplified Chinese**:
  > 使用 `/history-user` 查看你主角色和副角色每周的捐赠情况。

---

# `/daily`

**Purpose:** (Leader only) Send manual daily donation reminders.

- 🇬🇧 **English**: 
  > Leaders use `/daily` to select up to 3 users to manually remind them to donate today.

- 🇪🇸 **Español Latino**:
  > Los líderes usan `/daily` para seleccionar hasta 3 usuarios a quienes recordarles donar hoy.

- 🇨🇳 **Simplified Chinese**:
  > 领袖使用 `/daily` 手动选择3名用户进行今日捐赠提醒。

---

# `/report-week`

**Purpose:** Generate a donation report for the current week.

- 🇬🇧 **English**: 
  > Use `/report-week` to list who has donated, who hasn't, and download a CSV file for full review.

- 🇪🇸 **Español Latino**:
  > Usa `/report-week` para listar quién ha donado, quién no, y descargar un archivo CSV para revisión completa.

- 🇨🇳 **Simplified Chinese**:
  > 使用 `/report-week` 列出已捐赠和未捐赠的用户，并下载CSV文件以便完整检查。

---

# `/register-char`

**Purpose:** Register a new Main or Alt character.

- 🇬🇧 **English**: 
  > Use `/register-char` to associate a character name, type (Main or Alt), and its current clan.

- 🇪🇸 **Español Latino**:
  > Usa `/register-char` para asociar un nombre de personaje, tipo (Main o Alt) y su clan actual.

- 🇨🇳 **Simplified Chinese**:
  > 使用 `/register-char` 注册一个新角色（主角或副角）并关联其所属官民。

---

# 🏁 Notes

- Daily reminders are sent at 00:00 GMT-2.
- Commands `/daily` and `/report-week` are restricted to users with Leader roles.
- All reminders are sent in three languages together.
